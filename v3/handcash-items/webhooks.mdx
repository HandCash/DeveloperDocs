---
title: Sales Webhook
description: 'Receive notifications when an item sells on HandCash Market'
---

When a user sells an item on [HandCash Market](https://market.handcash.io) via a P2P listing, HandCash sends an HTTP `POST` to your app's `webhookUrl`.

<Note>
This webhook is for **market listing sales** only. Primary sales via payment requests use the [Payment Webhook](/v3/handcash-pay/webhooks). Peer-to-peer item sends do not trigger a webhook.
</Note>

## Setup

Set `webhookUrl` on your application record. Your endpoint must accept HTTPS `POST` requests and return `200` when processed.

## Event

| Field | Value |
| --- | --- |
| `event` | `item_listing_payment_completed` |
| `apiVersion` | `1.0` |

## Security

Verify the `handcash-signature` header on every request. It is an HMAC-SHA256 hex digest of the JSON body, keyed with your `appSecret`.

```typescript
import crypto from 'crypto';

function verifySignature(body: object, appSecret: string, signature: string): boolean {
  const expected = crypto.createHmac('sha256', appSecret).update(JSON.stringify(body)).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(signature));
}
```

## What does not trigger this webhook

- User-to-user item sends (`transferItems`)
- Primary sales completed via a payment request you created
- Item creation or mint orders
