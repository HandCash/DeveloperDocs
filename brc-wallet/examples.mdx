<Warning>
**Beta — BRC wallet only.** These examples talk to HandCash Desktop or Mobile over [BRC-100](https://brc.dev/100). They are not Connect or Wallet API samples.
</Warning>

Copyable request shapes live on the task pages: [payments](/brc-wallet/payments), [collectables](/brc-wallet/items), [tokens](/brc-wallet/tokens), and [signing](/brc-wallet/signing). The two projects below are the downloadable apps.

## Transaction Bounce

Sends 1,000 satoshis to the app and spends that exact output back to you, minus the network fee. The page calls the local wallet bridge. The refund API lives in the Worker.

Live app: [brc-cloud.bcryderman.workers.dev/tx-bounce](https://brc-cloud.bcryderman.workers.dev/tx-bounce)

<a href="/downloads/tx-bounce.zip" download>Download tx-bounce.zip</a>

The archive is the page, the refund API, and its tests. `TX_BOUNCE_PRIVATE_KEY` is a Worker secret and is not included.

## Wallet demo

Connects to HandCash on this device and runs one application lifecycle: identity, encryption, a 1,000-satoshi bounce, two JPEG inscriptions, and a BSV-21 mint. Wallet calls stay on the local bridge.

Live app: [brc-cloud.bcryderman.workers.dev/wallet-demo](https://brc-cloud.bcryderman.workers.dev/wallet-demo)

<a href="/downloads/wallet-demo.zip" download>Download wallet-demo.zip</a>

The archive is the page, the P2PKH helper, the tests, and the two JPEG bodies. The bounce step uses the Transaction Bounce API; that service key is not included.
